## 검색 개선

- 국내/해외 크롤러에서 관계없는 첫 결과를 채택하는 경로 제거 또는 제목 검사 추가.
- 한글 공백·구두점 정규화, 영어 단어 경계 및 권수 구분. `Clean Code`가 `The Clean Coder`에 연결되지 않도록 회귀 검사.
- 알라딘은 판매량을 적용하기 전에 제목 적합성 검사. ISBN은 ItemLookUp으로 조회. HTML 엔티티가 든 상품 URL 디코딩.
- 저자의 첫 해외도서를 원서로 가정하는 알라딘/Google/Yes24 폴백 제거. 원서 정보가 불확실하면 생략.
- Open Library 검색에 `isbn` 필드 명시 및 제목 검사 추가.
- 교보의 기존 통계 API가 JSON 대신 Not Found HTML을 반환함을 확인. 검색 결과의 `.review_klover_text`와 `.review_desc`에서 동일 상품의 점수·평가 수 수집.
- 국내 결과를 원서 조회 완료 전부터 스트리밍. 원서 조회의 동기 HTTP를 ASGI 이벤트 루프 밖에서 실행.
- JSON/SSE 검색 경로 통일. SSE 이벤트가 네트워크 청크 사이에서 분리돼도 종류·UTF-8 문자를 보존. 연결 종료 시 완료 이벤트가 없으면 오류 표시.
- 캐시 플랫폼 범위 분리, 선택 플랫폼으로 요약 재계산, 빈 플랫폼/잘못된 입력 거부, 중복 플랫폼 제거.
- SQLite 기록 저장·상세·목록·정렬·필터 지원. 설명 생성은 요청 시에만 실행. 수집 누락 플랫폼 표시.
- 웹 의존성 갱신 및 PostCSS 버전 통일. `npm audit` 0건.
