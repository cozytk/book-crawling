# 원서 연결 복구와 분권 평점 집계

확인 시각: 2026-10-29 KST. 실제 사이트 응답은 시점·실행 위치에 따라 달라진다. 회귀 테스트와 실제 서버 수집 결과를 별도로 기록한다.

## 배포

- 운영 웹: https://book-crawling.vercel.app
- 운영 API: https://book-crawling-api.vercel.app
- API production: `dpl_5fXXo26SY161TCbLBEUKAMSEB4LF`, 실행 코드 `84b5e70`, 서울 `icn1`.
- 웹 production: `dpl_AY5Db8jijBAEHw5qgM2dqehhXBTU`, 실행 코드 `f7d6698`. 이후 커밋은 Amazon 후보 정렬과 문서 변경이므로 웹 소스는 동일하다.
- 각각 production 환경으로 먼저 빌드·검증한 뒤 같은 배포를 promote했다. 캐시 스키마는 11이다.
- Next.js, Python Functions, 비공개 Vercel Blob으로 서비스한다. 운영 요청에서 GCP·Supabase를 사용하지 않는다. 기존 원격 DB 데이터의 복구·이전은 이번 변경에 포함하지 않았다.

## LibraryThing: 차단과 원서 식별 실패를 분리

`남아 있는 나날`은 평점 파서보다 앞선 원서 ISBN 조회에서 실패했다. Yes24가 제공한 저자 별칭 `Kazuo Ishiguro, カズオ イシグロ, 石黑 一雄`을 모두 검색어에 넣어 Open Library가 서로 다른 표기의 동시 일치를 요구하게 됐다. 제목과 호환되는 문자 체계의 저자 별칭 하나로 검색하고, 원래 저자 정보는 후보 검증에 보존했다.

`참을 수 없는 존재의 가벼움`은 검증된 국내 판본의 원제 `L'insoutenable légèreté de l'être`에서 아포스트로피를 그대로 보낸 카탈로그 검색이 해설서를 반환했다. 공백으로 정규화한 `L insoutenable légèreté de l être Milan Kundera`는 실제 프랑스어 판본으로 연결됐다. 카탈로그 후보는 제목·저자 검사를 통과해야 한다. 제목의 설명 부제보다 주제목을 먼저 조회하며, 제목 경로가 실패하면 검증된 국내 ISBN의 Edition→Work 연결도 사용한다. 책별 주소·작가명·평점을 하드코딩하지 않았다.

HTML의 Cloudflare 챌린지 대신 기존에 도입한 공개 Work Info API에 검증된 동일 작품의 ISBN 묶음을 전달한다. JSONP를 실행하지 않고 파싱하며 보고 척도 10점을 5점으로 변환한다. `copies`는 평가 참여 수로 사용하지 않는다. API의 `reviews`는 글 리뷰 수로 보존한다. 사용자 제공 URL의 `__cf_chl_tk`와 브라우저 쿠키는 수집기에 복사하지 않았다.

실제 Vercel 서버에서 다음 작품 연결과 숫자 평점을 확인했다.

| 검색어 | LibraryThing 작품 | 5점 척도 | 글 리뷰 수 |
| --- | --- | ---: | ---: |
| 남아 있는 나날 | [3035](https://www.librarything.com/work/3035) | 4.200 | 543 |
| 참을 수 없는 존재의 가벼움 | [5068](https://www.librarything.com/work/5068) | 4.000 | 312 |
| 전쟁과 평화 | [995](https://www.librarything.com/work/995) | 4.255 | 521 |
| 인간의 굴레에서 | [7701](https://www.librarything.com/work/7701) | 4.060 | 171 |
| 사피엔스 | [14300164](https://www.librarything.com/work/14300164) | 4.145 | 474 |
| 레 미제라블 | [19485](https://www.librarything.com/work/19485) | 4.265 | 385 |

외부 카탈로그가 시간 초과되면 원서 연결도 여전히 실패할 수 있다. LibraryThing API의 이용 조건과 프로세스 단위 요청 제한은 [이전 조사](source-discovery-20261028.md)를 따른다. 여러 Vercel 인스턴스에 걸친 전역 속도 제한은 구현하지 않았다.

## Amazon: 실제 HTML 파싱 개선, 서버 차단은 남음

브라우저에서 실제 검색 URL `https://www.amazon.com/s?k=The+Remains+of+the+Day&i=stripbooks`와 도서 상세를 조사했다. 같은 공개 URL에 일반 HTTP와 브라우저 호환 HTTP를 비교했다. 로컬에서 일반 HTTP 검색은 503, 브라우저 호환 검색은 상품 카드 21개가 있는 200이었다. 반대로 상세는 일반 HTTP가 실제 도서를 반환하고 브라우저 호환 HTTP가 체크포인트로 이동했다. 따라서 검색 `/s`에만 연결 재사용·취소를 지원하는 브라우저 호환 전송을 적용하고 상세 경로는 일반 HTTP를 유지했다.

- 현대 검색 카드의 제목·ASIN·저자 byline을 검증한다. 검증한 카드에 평점이 있으면 상세 요청을 생략한다.
- `data-cy="reviews-block"`의 집계 별점과 평점 참여 수를 추출한다. popover의 ASIN이 다른 상품이면 거절한다.
- 영어·한국어 별점 문구를 처리하고 `29,411 ratings` / `29,411개 평가` 라벨에서 정확한 참여 수를 읽는다. `(29.4K)`와 `(2.9만)`을 정확한 정수로 추정하지 않는다.
- 제목·저자가 검증된 후보 중 평점이 있는 판본을 먼저 검토한다. ISBN-13의 978 접두어를 ISBN-10으로 변환해 `/dp/{ASIN}`을 구성한다. 979 ISBN을 그대로 13자리 `/dp/`에 보내지 않는다.
- 상세 ISBN은 명시적인 상품 정보 행에서만 수집한다. 추천 도서의 ISBN이나 페이지 전체 숫자를 판본 근거로 쓰지 않는다.
- HTTP 200이라도 Robot Check·체크포인트·CAPTCHA 응답이면 `blocked`로 분류한다. 챌린지를 풀거나 사용자 브라우저 쿠키를 서버에 전달하지 않는다.

로컬 실제 수집에서 `남아 있는 나날`의 검증된 검색 카드 `0679731725`로 **4.4/5, 별점 참여 29,411건**을 Amazon HTTP 요청 1회로 얻었다. Vercel의 첫 production 검증 배포(`f7d6698`)에서는 쿤데라 작품 `2072892651`의 **4.5/5, 별점 참여 1,535건**을 수집했다. 그러나 다음 배포(`84b5e70`)의 강제 재조회에서는 같은 작품도 차단됐고, `남아 있는 나날`의 제목 검색·두 ISBN 직접 조회도 차단됐다. **Amazon의 Vercel 서버 수집 제한을 해결했다고 판단하지 않는다.** Goodreads도 재조회에 따라 차단되거나 결과가 누락됐다. 숫자가 없는 실패 응답을 0점·0건으로 채우지 않는다.

공식 [Amazon Creators API 등록 조건](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/onboarding/register-for-creators-api)과 [SearchItems](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/api-reference/operations/search-items)도 확인했다. 승인된 Associates 계정과 이용 요건·자격 증명이 필요하며 현재 서비스에는 해당 설정이 없다. 임의 가입이나 구매는 진행하지 않았다.

## 여러 권은 같은 출판사·번역자 안에서 단순 평균

사용자가 선택한 계산은 **권별 단순 평균**이다. 먼저 검증한 원저자의 후보만 남기고, 출판사·번역자·주제목·분권 여부가 같은 후보를 묶어 관측된 평가 수가 많은 묶음을 선택한다. 같은 권의 중복 상품은 하나만 남긴다. 세트 상품은 총 권수 확인에 사용할 수 있지만 권별 평점과 중복 합산하지 않는다.

교보의 실제 [레 미제라블 검색](https://search.kyobobook.co.kr/search?keyword=%EB%A0%88+%EB%AF%B8%EC%A0%9C%EB%9D%BC%EB%B8%94&gbCode=TOT&target=total)에서 민음사·정기수 번역 1~5권을 선택했다. 이 5개 ISBN을 교보·알라딘·Yes24·사락에 공유하며, 특정 권을 찾지 못했다고 다른 출판사나 다른 권으로 대체하지 않는다.

| 권 | ISBN | 교보 원점수 | 관측 평가 수 |
| --- | --- | ---: | ---: |
| 1 | 9788937463013 | 9.7 | 53 |
| 2 | 9788937463020 | 9.9 | 35 |
| 3 | 9788937463037 | 10.0 | 25 |
| 4 | 9788937463044 | 9.6 | 24 |
| 5 | 9788937463051 | 10.0 | 22 |

교보 평균은 `(9.7 + 9.9 + 10 + 9.6 + 10) / 5 = 9.84`이다. 리뷰 수로 가중하지 않는다.

실제 Vercel 배포에서 국내 네 소스 모두 같은 ISBN 5/5권을 수집했다.

| 플랫폼 | 권별 단순 평균 / 10 | 수집 범위 |
| --- | ---: | --- |
| 교보 | 9.84 | 5/5권 |
| 알라딘 | 9.44 | 5/5권 |
| Yes24 | 9.38 | 5/5권 |
| 사락 | 9.30 | 5/5권 |

왓챠의 작품 전체 레코드 `b4eY5X4`는 4.1/5로 한 번만 표시한다. LibraryThing·Goodreads·Amazon처럼 작품/외국 판본 평점을 제공하는 곳에도 같은 레코드를 다섯 권처럼 복제하지 않는다. 사용자가 ISBN이나 특정 권을 검색하면 분권 집계를 하지 않는다. 실제 운영 API에 ISBN `9788937463037`을 조회해 네 소스 모두 3권의 지정 판본만 반환함을 확인했다.

누락된 권은 실패 상태와 함께 남기고, 확인한 권의 평균에는 `일부 권 미확인`을 표시한다. 전체 권이 완성되고 모든 권의 수치가 확인된 경우에만 평가 수를 합산한다. 권별 합계는 사람의 중복을 제거한 고유 인원 수가 아니다. 검색 목록에 노출된 후보와 확인된 총 권수 안에서 수집하므로 모든 책의 모든 판본을 망라하는 카탈로그 기능은 아니다.

화면은 `권별 평균`, 출판사·번역자, 확인한 권수, 각 권의 원점수·ISBN·상품 링크를 표시한다. `권별 점수와 상품 보기`를 펼치면 1~5권을 확인할 수 있다. 운영 브라우저에서 결과 업데이트·저장 기록 재조회·상세 펼침을 확인했고, 402×681 CSS px 모바일 에뮬레이션에서 가로 넘침 없이 링크 5개가 표시됐다. 실기기 Safari 검증은 아니다.

## 검증 범위

- Python 3.12 회귀 테스트 **255개 통과**. 의존성의 deprecation 경고 12건.
- 웹 SSE 테스트 2개, TypeScript·Next.js production 빌드, GitHub backend/web/guard 검사 통과.
- 모의 응답 회귀: 다국어 저자 별칭, Amazon 현대 카드·정확/축약 수치·다른 ASIN·상품 ISBN·평점 있는 판본 선호, 출판사/번역자별 묶음, 단순 평균, 누락/중복 권, ISBN 고정, 실패 상태와 캐시 왕복.
- 실제 서버: LibraryThing 위 6개 작품, 레 미제라블 네 소스의 5권과 평균, 지정 ISBN, 운영 웹→API→SSE→Blob 저장/상세 조회.
- 레 미제라블 국내 4개 소스+왓챠의 로컬 실제 조회는 HTTP 28회(교보 1, 알라딘 10, Yes24 10, 사락 5, 왓챠 2). Vercel 8개 소스 조회는 총 34~35회, 11.896~16.397초였다. 외부 차단 여부가 달라 동일 조건의 속도 향상 수치로 해석하지 않는다. 첫 결과·오탐률·누락률의 전체 코호트 재측정은 이번 추가 검증에서 수행하지 않았다.

이전 전후 10개 입력 비교와 검색 주소·식별 규칙은 [source-discovery-20261028.md](source-discovery-20261028.md)에 있다. 이번에는 실제 서버 성공과 로컬 성공, 이후 재조회 실패를 구분해 기록했다. 재현용 실행 결과는 비공개 로컬 `artifacts/`에 보관하고 인증 파일은 커밋하지 않았다.
